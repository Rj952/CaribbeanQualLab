# Creative rights and authorship

**The Caribbean Qualitative Research Lab was conceived, designed and created by Dr. Rohan Jowallah.**

## What Dr. Jowallah created
- **The analytical framework:** the seven-stage research journey *Evidence → Coding → Literature → Inference → Interpretation → Triangulation → Write-up*, and the principle that every finding must stay linked to participants' own words.
- **The analytical-defence approach:** for each excerpt, the student justifies the code (“Why does this code fit?”) and records inference, interpretation and triangulation as separate, traceable steps.
- **The Caribbean design:** language and context notes that preserve Jamaican Creole and other Caribbean language varieties in participants' own words; a low-bandwidth, offline, Moodle-ready design; and the colour and visual identity.
- **The software:** its interface, structure and workflow.
- **The guidance, practice study and documentation** in this repository.
